# SMART STOCK V1.0 — source prototype
Android Studio / JDK 17 / Gradle 8.9 / Android SDK 35. Build: gradle :app:assembleDebug. Debug APK is not a permanent release. ZXing embedded camera scanner dependency is downloaded at build time. Runtime is offline.
Import a prepared single-sheet XLSX with zero quantities, literal costs, and barcode text. Original workbook is retained; export updates quantity and total only (adds total column if absent). Multiple matching barcodes require explicit row selection. One active session is stored locally; export before replacing. Android print dialog offers PDF or installed print service. No currency conversion. This prototype has not been built or tested on Android. No permanent signing key, multi-session backup, or full audit history is included yet. Test print pagination and Excel formatting on real device before use. Do not import unprepared formula workbooks for operational use.
