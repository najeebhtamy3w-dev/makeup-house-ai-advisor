# AI COUNCIL — حزمة Claude Code (الإصدار 2.0.0)

مجلس خبراء استشاري متعدد الوكلاء يعمل **عند الطلب فقط**. الوضع الافتراضي دائمًا هو **NORMAL MODE**.

- **الأعضاء التسعة** وكلاء فرعيون حقيقيون (Subagents). لكل عضو سياق مستقل ونموذج `sonnet`، وأدواته مقيّدة تقنيًا بـ `Read, Grep, Glob` فقط. لا يستطيع العضو الكتابة أو تنفيذ الأوامر.
- **رئيس المجلس** هو الجلسة الرئيسية نفسها. يعمل وفق `skills/council/PROTOCOL.md`.
- **لا تحتوي الحزمة على أي Hooks أو إعدادات أو عمليات خلفية.** لا تعدّل `settings.json` ولا `CLAUDE.md`.

## الأوامر

| الأمر | البديل العربي | ما يحدث |
|---|---|---|
| `/council <الموضوع>` | «اجمع المجلس …» | مجلس اعتيادي من 5 خبراء |
| `/council-quick <الموضوع>` | «اجمع المجلس السريع …» | مجلس سريع من 3 خبراء وجولة واحدة |
| `/council-full <الموضوع>` | «اجمع المجلس الكامل …» | الخبراء التسعة كلهم، مع مراجعة نقدية |
| `/council-red-team <الموضوع>` | «فعّل الفريق المعارض …» | الفريق المعارض، ومعه عضوان على الأكثر |
| `/council-release <الموضوع>` | «اجمع مجلس الإصدار …» | مراجعة جاهزية الإصدار، دون بناء أو توقيع أو نشر |
| `/council-status` | «ما حالة المجلس؟» | عرض الحالة دون تشغيل أي وكيل |
| `/council-stop` | «أوقف المجلس» / «الوضع العادي» | إيقاف المجلس والعودة إلى الوضع العادي |

- **إذا ثُبّتت الحزمة كإضافة (Plugin):** تصبح الأوامر `/ai-council:council` وما شابهها، وأسماء الوكلاء `ai-council:council-*`.
- **الأوامر التي تبدأ بشرطة مائلة:** عليها `disable-model-invocation: true`، أي أن النموذج نفسه لا يستطيع تشغيلها. يشغّلها المالك بكتابتها فقط.
- **الأوامر العربية:** تمر عبر مهارة واحدة اسمها `council-ar`، وهي مقيدة بالعبارات الصريحة. مجرد ذكر كلمة «المجلس» لا يشغّلها.

## التثبيت

```bash
# على مستوى المستخدم (لكل المشاريع على هذا الجهاز)
./install.sh
# أو داخل مشروع واحد فقط
./install.sh --project /path/to/project
# أو كإضافة
claude plugin marketplace add /path/to/AI_COUNCIL_CLAUDE_CODE_V2
claude plugin install ai-council@ai-council-marketplace
```

- يأخذ المثبّت نسخة احتياطية من أي ملف `council-*` قائم لم ينشئه هو، ويضعها في `~/.claude/ai-council/backups/<timestamp>/`.
- يسجّل الملفات التي ثبّتها في `~/.claude/ai-council/INSTALLED_FILES`.
- بعد التثبيت ابدأ جلسة جديدة حتى تُحمَّل الوكلاء، ثم جرّب `/council-status`.

## التحديث

اسحب أحدث نسخة من الحزمة، ثم شغّل `./install.sh` مرة أخرى. التثبيت المتكرر آمن، والمثبّت لا يأخذ نسخة احتياطية من ملفاته هو.

## إلغاء التثبيت

```bash
./uninstall.sh                          # يحذف الملفات المسجلة فقط
./uninstall.sh --restore-latest-backup  # ويستعيد ملفاتك السابقة إن وُجدت
```

## الاستمرارية في الجلسات السحابية (والتشغيل من تطبيق الهاتف)

جلسات Claude Code السحابية تبدأ كل مرة في حاوية جديدة، فلا يبقى فيها `~/.claude` من جلسة سابقة. لجعل المجلس متاحًا تلقائيًا في كل جلسة، أضف هذا السطر إلى **Setup script** في إعدادات البيئة. يشغّل السطر المثبّت إذا وُجدت الحزمة في أي مستودع من مستودعات الجلسة:

```bash
for d in */AI_COUNCIL_CLAUDE_CODE_V2 */ai-council; do [ -x "$d/install.sh" ] && bash "$d/install.sh" && break; done; true
```

- **شرط مهم:** يجب أن تكون الحزمة موجودة في الفرع الذي تستنسخه الجلسة، وهو الفرع الافتراضي في العادة. يُفضَّل وضعها في مستودع مستقل (مثل `ai-council`) وإضافته إلى البيئة.
- **من الهاتف:** افتح جلسة Claude Code سحابية من تطبيق Claude، ثم اكتب `/council-quick …` أو «اجمع المجلس السريع …».

## سياسة الاستخدام

1. **NORMAL MODE هو الافتراضي.** البرمجة والإصلاح والاختبار والبناء تجري كالمعتاد دون المجلس.
2. **لا يعمل المجلس إلا بأمر صريح.** يجوز لـ Claude أن يقترحه في سطر واحد فقط.
3. **بعد كل جلسة مجلس:** يظهر سطر `RETURNED TO NORMAL MODE`، ولا يعود المجلس إلا بأمر جديد.
4. **المجلس استشاري.** توصياته لا تُغني عن الاختبارات الفعلية ولا عن الموافقات الإلزامية.

## التكلفة

- **عند عدم الاستخدام:** لا يُضاف إلى السياق إلا وصف الوكلاء التسعة ووصف مهارة `council-ar`، وهو نحو 550 إلى 600 token. مهارات الشرطة المائلة لا تُحمَّل في السياق إطلاقًا.
- **المقاييس من الاختبارات:**
  - `/council-status` ≈ 0.14$
  - مجلس سريع (3 أعضاء) ≈ 0.44$
  - فريق معارض (عضوان) ≈ 0.35$

  القيم بسعر القائمة، كما ظهرت في سجلات اختبارات هذا التثبيت، وتتغير بحسب حجم الموضوع.
