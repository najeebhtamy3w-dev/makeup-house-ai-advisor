# Samsung Android Validation (CP03, Phase D)
**Gate D: BROWSER-TESTED / DEVICE-PENDING.** لم يُختبر أي جهاز فعلي ولا قارئ HID حقيقي. لا يُدّعى نجاح الكاميرا الفعلية.

## اختُبر في المتصفح (Chromium مكتبي)
* `tests/device-page.mjs`: صفحة التشخيص `/device-test.html` — كاميرا وهمية (`--use-fake-device-for-media-stream`) تبدأ وتتوقف وتُحرَّر المسارات؛ محاكاة قارئ HID (كتابة سريعة + Enter) سجّلت 3 مسحات بينها مكرر؛ لا أخطاء وحدة التحكم؛ RTL. **ملاحظة:** `BarcodeDetector` غير متاح في هذا المتصفح، لذا قراءة الباركود بالكاميرا لم تُختبر.
* اختبارات واجهة 390×800: RTL، الشريط السفلي لا يغطي المحتوى، لا تمرير أفقي، رسائل رفض الكاميرا/عدم الدعم، الإدخال اليدوي، منع القراءة المكررة (قراءتان متطابقتان + 3ث) — منطقيًا.

## تعليمات اختبار الجهاز الحقيقي (≈10 دقائق)
**شرط:** الكاميرا تتطلب سياقًا آمنًا (HTTPS أو localhost).
* **الأسهل (بدون شهادات):** وصّل الهاتف بـUSB مع تفعيل «تصحيح USB»، على الحاسوب: `adb reverse tcp:8080 tcp:8080`، شغّل الخادم، ثم افتح في Chrome على الهاتف `http://localhost:8080/device-test.html` (localhost سياق آمن).
* **أو** HTTPS عبر نفق/شهادة محلية (قرارك؛ لا أفعّل خدمة مدفوعة).
### أ) صفحة التشخيص → «الكاميرا»
اضغط «تشغيل الكاميرا» ← امنح الإذن ← امسح باركودًا حقيقيًا (3 منتجات) في إضاءة عادية ثم خافتة ثم قرب لمبة قوية ← أبقِ الباركود أمام الكاميرا ثوانيَ (يجب ألا تتكرر القراءة خلال 3ث) ← «إيقاف» (يجب أن ينطفئ مؤشر الكاميرا).
جرّب رفض الإذن في محاولة ثانية (إعدادات الموقع ← الكاميرا ← حظر) وسجّل الرسالة.
### ب) HID (إن وُجد قارئ)
اقرن القارئ (USB-OTG/Bluetooth) ← انقر داخل حقل «امسح هنا» ← امسح 3 باركودات (أحدها مرتين متتاليتين) ← تحقق من ظهور Enter وسرعة الأحرف.
### ج) التطبيق نفسه
افتح `/` ← تسجيل الدخول ← «مسح»: امسح (1) منتجًا مسجلًا (2) باركودًا جديدًا (3) باركودًا غير صالح؛ جرّب الإدخال اليدوي؛ افصل الإنترنت أثناء البحث وتأكد من بقاء الباركود وزر إعادة المحاولة؛ اكتب في المستشار وراقب أن لوحة المفاتيح لا تغطي الحقل ولا الشريط السفلي؛ مرّر قائمة المنتجات؛ لاحظ مناطق اللمس.
### د) التقرير
في صفحة التشخيص اضغط «إنشاء التقرير» ← «نسخ» وأرسل JSON مع: طراز الهاتف، نسخة Android، نسخة Chrome، وملاحظات (إضاءة، سرعة، مشاكل لمس/RTL/لوحة مفاتيح).
