## 3. نموذج لغوي محلي على الهاتف
| البند | القياس / التقدير |
|---|---|
| ARM64 | llama.cpp يدعم ARM64 وAndroid (NDK)؛ ثنائيات linux-arm64 من node-llama-cpp ≈20 MB لعدة متغيرات CPU (≈1 MB لكل متغير + القاعدة) — مؤشر لحجم المكتبة الأصلية؛ لم يُبنَ لـ Android |
| حجم النموذج | 0.64 GB (0.6B) … 2.5 GB (4B Q4) — **لا يوضع داخل APK** (حدود Play، وتحديثات ضخمة)؛ يُنزّل منفصلًا أو يُستورد يدويًا كما يفعل AiPaca |
| RAM | على الحاسوب: 2.1 GB (0.6B) إلى 5.9 GB (4B) مع سياق 4096؛ على الهاتف أقل بسياق أصغر لكن 4B يتطلب جهازًا بذاكرة 8 GB+ ونظام Android قد يقتل التطبيق |
| السرعة | الحاسوب: 4B ≈6 رموز/ث ≈27 ث للإجابة؛ هاتف متوسط أبطأ عادة — **غير مقبول للبيع وجهًا لوجه** |
| البطارية والحرارة | NOT VERIFIED؛ متوقع مرتفع عند الاستدلال المستمر |
| زمن البدء | 2–3 ث تحميل على الحاسوب؛ NOT VERIFIED على الهاتف |
| التكامل | WebView لا يشغّل llama.cpp؛ يلزم إضافة Capacitor أصلية (Kotlin + JNI) أو خدمة منفصلة كنمط AiPaca — **تعديل Android وإضافة أصلية = غير مفوّض** |
| نقص الذاكرة | يجب الرجوع إلى LOCAL_RULES (مصمم: المحرك `null` ← القواعد) |
| الترخيص | Qwen3 Apache-2.0 مناسب؛ نسخ كود AiPaca (GPL-3) غير مناسب |
