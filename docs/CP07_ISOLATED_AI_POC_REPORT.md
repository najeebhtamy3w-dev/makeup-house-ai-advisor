# CP07 — Phase 9: تجربة الذكاء الاصطناعي المفتوح المعزولة

**الحالة: VERIFIED (تعمل وقابلة لإعادة الإنتاج على حاسوب التطوير).** المجلد: `experiments/cp07-open-source-ai/` — لا يستورده التطبيق ولا العامل ولا Render.

## 1. ما بُني
| المكوّن | الوصف |
|---|---|
| `AIEngineAdapter` | `initialize` · `generate` (مهلة، حد رموز، حرارة، JSON Schema اختياري) · `cancel` (AbortSignal) · `healthCheck` · `dispose` |
| `LlamaCppEngine` | llama.cpp (MIT) عبر node-llama-cpp 3.22.3، CPU، سياق 4096 |
| `MockRemoteEngine` | `REMOTE_MODEL_OPTIONAL`: صدى مؤرض / تلفيق / تعطل — **لا خدمة سحابية، لا مفتاح، تكلفة 0** |
| `hybridAnswer()` | المسار الكامل: سؤال ← فهم ← استرجاع ← أدلة ← (قواعد) ← صياغة النموذج ← حارس ← استشهاد؛ أي فشل ← `LOCAL_RULES` |
| `bench-model.ts` | قياس نموذج واحد في عملية مستقلة (ذاكرة نظيفة) |

## 2. المسار المختبر (Question → Understanding → Retrieval → Evidence → Reasoning → Answer → Citation)
- **الفهم:** قواعد CP07 (والنموذج اختياريًا كـ JSON مقيد — جُرّب وقورن).
- **الاسترجاع/الأدلة/الاستدلال:** CP07 دائمًا (النموذج لا يسترجع ولا يقرر الملاءمة).
- **الإجابة:** النموذج يعيد صياغة العناصر المؤرضة فقط.
- **الاستشهاد:** يُتحقق منه آليًا؛ المصادر تُلحق من CP07 لا من النموذج.
- **لا تُرسل للنموذج أبدًا:** علامات الخطر، الأسئلة خارج النطاق، إجابات «معلومات غير كافية».

## 3. الأوضاع الثلاثة (VERIFIED)
| الوضع | النتيجة |
|---|---|
| LOCAL_RULES | <2 ms، دون اتصال، الافتراضي — 166/166 اختبار خادم |
| LOCAL_MODEL | يعمل مع 5 نماذج؛ اجتياز الحارس من 1/12 إلى 12/12؛ زمن 8–27 ث للإجابة؛ رجوع آلي سليم عند كل فشل |
| REMOTE_MODEL_OPTIONAL | Mock فقط: الصدى المؤرض يُقبل، التلفيق (مصدر + رابط + «100%») يُرفض ويرجع للقواعد، التعطل يرجع للقواعد (اختبار 11) |

**إيقاف النموذج لا يعطّل المستشار:** إذا كان المحرك `null` أو غير سليم أو انتهت المهلة أو رُفض المخرج ← نص LOCAL_RULES نفسه.

## 4. ما أثبتته التجربة
1. التشغيل المحلي المجاني ممكن تقنيًا (CPU، دون إنترنت بعد تنزيل الأوزان).
2. **القيمة المضافة ضعيفة والمخاطر حقيقية:** النماذج الصغيرة إما تنسخ (قيمة صفر) أو تعيد الصياغة مع انزياح في المعنى لا يكشفه حارس آلي (انظر `CP07_LOCAL_MODEL_BENCHMARK.md` §3).
3. الحارس فعّال ضد التلفيق البنيوي (التقط استشهادات مخترعة، مخرجات فارغة، لغة أخرى) — يبقى ضروريًا لأي تكامل مستقبلي، **ويحتاج إضافة فحص دلالي** (مثل منع كلمات التقوية «نعم/أثبتت/دراسات علمية» غير الموجودة في الادعاء، ومنع تحويل «اسأل الطبيب» إلى «ممنوع») قبل أي استخدام.
