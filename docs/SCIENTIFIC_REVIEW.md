# المراجعة العلمية والتجميلية (CP02)
> هذه مراجعة لمنطق النظام وحدوده، لا ادعاء لمرجعية طبية. لا يستخدم النظام أي محتوى علمي غير موثق كحقيقة.

## القواعد المنفذة (وكل منها مختبر)
| القاعدة | التنفيذ |
|---|---|
| لا «خالٍ من العطر» دون مكونات موثقة | اسم المنتج/تسويقه يُتجاهل؛ المنتج بلا مكونات → «لا يمكن تقييمها» |
| لا «آمن للحساسة» | ملاحظة ثابتة عند ذكر الحساسية: لا منتج آمن لجميع الأشخاص |
| أعراض مقلقة (تورم، حروق، طفح/حكة شديدة، نزيف، صديد…) بأي تهجئة | لا توصية منتج + إحالة لمختص |
| حبوب/قشرة/تساقط | ملاحظة إحالة؛ لا وعود علاجية |
| لا وعود علاجية من أي مزود لغوي مستقبلي | `guardGrounding` يرفض «يعالج/يشفي…» والأسعار والمنتجات غير المسترجعة |
| التفريق بين الملاءمة والتوفر | كتلتان منفصلتان؛ الملاءمة تحدد الترتيب والتوفر مجرد مرجّح ثانوي |
| معلومات متعارضة | تُخفّض الملاءمة إلى «جزئية» وتُعلن |
| معلومات المصادر العالمية | مسودات فقط؛ الاعتماد يحدّ الحالة عند «جزئي»؛ «معتمد» يتطلب تعديل المدير برابط مصدر؛ أي تعديل يُسقطه |
| لا درجة ثقة رقمية | مستويات وصفية: موثقة/جزئية/غير معروفة |
| الإصدار/السوق | لا يُدمج تركيبان: الباركود هو المعرّف؛ تعارض القيم يظهر للمدير |

## حدود معروفة (صريحة)
1. **فحص العطر كلمات مفتاحية** (`parfum|fragrance|perfume|aroma|عطر`). لا يكشف مسببات الحساسية العطرية المسمّاة (مثل linalool/limonene) ولا الزيوت العطرية. **ليس تحليلًا للمكونات.** مطلوب مرجع مكونات موثق قبل ترقيته.
2. **لا تقييم ملاءمة قائم على المكونات** لنوع البشرة (الجفاف/الدهنية/حاجز البشرة/الحبوب) — الملاءمة الآن = تطابق التصنيف + اكتمال التوثيق. هذا **NOT IMPLEMENTED** عمدًا: لا يوجد مصدر علمي معتمد داخل المشروع لربط مكوّن بنوع بشرة.
3. **بيانات Open Beauty Facts تطوعية** وقد تكون قديمة أو خاطئة؛ لذلك تبقى مسودات ولا تتجاوز «جزئي».
4. **SPF:** الدرس يذكر UVB وفق الاختبار؛ لا يحسب النظام حماية UVA ولا يوصي بكمية.
5. **الروتين:** ترتيب عام فقط (تنظيف ← ترطيب ← واقي شمس). لا تداخلات بين مكونات فعالة (retinoids/أحماض…) لأنها غير مدخلة وغير موثقة.
6. الدروس الخمسة في الأكاديمية مبادئ عامة مصاغة بحذر ولم تُراجع من مختص؛ **تُراجع قبل الاعتماد التدريبي**.

## توصية
تعيين مختص تجميل/صيدلة لمراجعة: قائمة الأعراض المحيلة، نص الأكاديمية، ثم بناء جدول مكونات موثق (مصدر + تاريخ) قبل أي تقييم مبني على المكونات.
