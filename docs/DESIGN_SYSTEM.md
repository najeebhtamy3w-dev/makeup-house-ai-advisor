# نظام التصميم v1 (مستخرج من `web/styles.css`)
* **الألوان (رموز):** وردي غباري `--rose-50/100/200/500`، عنابي `--wine-600/700/800`، عاجي `--ivory`، كريمي `--cream`، محايدات `--ink/--muted/--line`، حالات `--ok/--warn/--err`. الوردي للخلفيات الخفيفة والعنابي للإجراء الرئيسي فقط.
* **الخط:** `Noto Sans Arabic` ثم `Segoe UI/Tahoma` (لا تحميل خطوط خارجية لسرعة الهاتف).
* **المسافات/الزوايا/الظلال:** زوايا 10/14/20px، ظلان خفيفان `--sh-1/2`، هدف لمس ≥ 44px (الأزرار الصغيرة 38px).
* **المكونات:** `.btn` (أساسي/خفيف/محدد/خطر/صغير/مشغول)، `.card`، `.badge`(ok/warn/no/info)، `.notice`، `.chip`، `.cand` (مرشح مصدر)، `.skel` (هيكل تحميل)، `.sheet`، الشريط السفلي.
* **الحركة:** انتقالات 120–220ms للتوضيح فقط (ظهور، ضغط زر، إطار المسح). **لا مؤشرات «تفكير ذكاء اصطناعي» وهمية**: الانتظار هيكل رمادي فقط. `prefers-reduced-motion` يعطل كل الحركة (مختبر).
* **الوضع الداكن:** رموز `[data-theme=dark]` مجهزة، **غير مفعّلة وغير مختبرة**.
* **إمكانية الوصول:** `aria-live` للمحادثة، `aria-pressed` للفلاتر/التوفر، `role=alert` للأخطاء، تركيز مرئي. لم يُجرَ اختبار قارئ شاشة فعلي.
