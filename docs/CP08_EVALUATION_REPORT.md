## 3. إخفاقات ممثِّلة متبقية (العمياء، بعد القياس النهائي — لم تُصلح لإبقاء الرقم نظيفًا)
| السؤال | الخطأ |
|---|---|
| «محتاجه كريم للبشره الناشفه جدا في الشتا» | لم يُفهم كطلب مرطب («كريم» دون «مرطب») |
| «كيف اقلل لمعة الوجه بدون ما انشفه» | غير مفهوم (لا نوع بشرة ولا نية) |
| «هل لازم واقي شمس لو ما طلعت من البيت» | فُهم طلب منتج بدل سؤال شرح |
| «السيليكون في الشامبو يضر؟» | فُهم طلب شامبو بدل سؤال مكوّن |
| «ودي بمرطب بدون ريحة لاني **اتحسس**» / «بشرتها **عادية**» | نوع البشرة لم يُلتقط |
| «… وما ابغى فيه عطر» | القيد بصيغة نفي لم يُلتقط |
| «الكولاجين **بالحبوب**…» / «زيت الشاي الأخضر للحبوب» | لم يُعترف بنقص المعرفة |
| «شعري **ينكسر**…» | التلف لم يُلتقط |

لا شيء منها متعلق بالسلامة.
