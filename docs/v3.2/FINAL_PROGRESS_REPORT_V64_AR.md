## التنفيذ المثبت

- المستشار الرئيسي والمستشار التجريبي يستخدمان نواة واحدة، ومسار Android يستدعي Native Bridge. حالات installed / active / loaded / verified منفصلة، والفشل وFallback ظاهران، ومختبر المدير يتيح النص الخام والمقاييس بوصفه غير معتمد.
- ذاكرة سياق محدودة، أدوات قراءة حقيقية، حماية التحذيرات والإحالات، معرفات منتجات وأدلة مقيدة، وعدد استدعاءات وإعادة محاولات محدود. لا تمنح هذه البنية وحدها قبول الفهم أو الاستدلال.
- OCR عربي/إنجليزي محلي بـ Tesseract4Android4.9.0 وأوزان eng+ara مثبتة الإصدار والبصمة. بُني Android فعليًا في Run45831293938؛ قراءة منتجات حقيقية على Samsung غير مختبرة. نقل النص إلى INCI يحتاج مراجعة، والحفظ يحتاج تأكيدًا.
- VLM فعلي على Host باستخدام Qwen3.5-2B نفسه وملحق mmproj-F16 المتوافق. اختُبرت صورتان اصطناعيتان معلّمتان بوضوح، وتغيّرت النتائج مع الصورة. Wrapper انتهى عند EOS، وحدود الصورة8/8، والإلغاء أثناء Prefill ثم الاستعادة نجحا. أخطأ في الشكل؛ لا قبول لدقة المنتجات أو INCI.
- مسار الرؤية في Android/JNI وإدارة Projector اختياري مستقل وصلا بالواجهة. الوصف التجريبي للمدير `validated:false`، ولا يحفظ بطاقة أو هوية أو مكونات تلقائيًا. يحتاج بناء Android وتشغيل الهاتف لإثباته؛ نجاح Host لا يعوّض ذلك.
- الصور ومسودات المنتجات والباركود والمخزون تستعمل وظائف وقاعدة بيانات فعلية، مع فصل الكتالوج العالمي عن الدفعات المحلية والصلاحية. حفظ الصورة لا يثبت فهمها أو أصالة المنتج.

النموذج الأساسي بقي Qwen3.5-2B Q4_K_M، بحجم1280835840 وبصمة aaf42c8b7c3cab2bf3d69c355048d4a0ee9973d48f16c731c0520ee914699223. المقارنات السابقة مع4B وPhi لم تثبت تفوقًا يبرر التبديل. لم يُعد تنفيذها في هذه الاستعادة. مدير النماذج الحالي مثبت على Baseline المعتمد؛ التبديل العام بين GGUF والاستيراد المحلي غير مكتملين، ولا يُدّعى أن اختيار نموذج جديد لا يحتاج قبولًا مستقلاً.
