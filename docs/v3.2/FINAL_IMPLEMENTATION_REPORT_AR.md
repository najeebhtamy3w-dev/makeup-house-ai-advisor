## العربية والذاكرة والخصوصية

يستقبل النموذج العربية واللهجة اليمنية والمزج اللغوي؛ لا توجد حتى الآن نسبة نجاح ممثلة أو مراجعة لغوية مؤهلة تسمح بالقول إنه يفهم اللهجة المطلوبة بمستوى القبول. صلاحية JSON لا تساوي فهم النفي أو الغموض. حالات التطوير تشمل هذه المشكلات، لكن نجاحها التوليدي يجب أن يقاس.

الذاكرة حقول بشرة/شعر/احتياجات/قيود/مكونات ومراجع منتجات ضمن جلسة تملكها هوية الموظف. correction يستبدل السياق القابل للتصحيح، وتمنع revision CAS تعارض الطلبات، والتذكرة أحادية الاستخدام ومقيدة بالمالك. حذف الجلسة يحذف الذاكرة والتشخيصات. الأسئلة الخام ومعلومات العميل الشخصية لا تحفظها سجلات المنسق الجديدة؛ الاستمرارية ليست تذكرًا حرًا لكل محادثة سابقة أو تلخيصًا عصبيًا طويل الأمد. لا يجوز ادعاء تذكر ما لم يعد متاحًا.

سجل المدير يبين provenance والأدوات والمعرفات والمدة والمحاولات وسبب Fallback. تصنيفات evidence_selection أو clarification أو emergency أو Fallback منفصلة عن generative_first/retry؛ تشغيل النموذج لا يحتسب اكتمالًا ذكيًا. لا يجوز تحويل نجاح الاختبارات الاصطناعية لهذه العدادات إلى نسبة نجاح استشارات حقيقية.
