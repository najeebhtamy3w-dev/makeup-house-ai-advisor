# تدقيق المعرفة والربط المحلي — V3.2

الحالة: IMPLEMENTED / VERIFIED للاختبارات البرمجية المحلية؛ PARTIAL للتغطية العلمية؛ NOT TESTED للمراجعة العلمية البشرية والهاتف.

## خط الأساس المعاد قياسه

جرى فتح SQLite جديدة بواسطة migrations الفعلية وتشغيل seedKnowledge، وليس الاعتماد على الأرقام التاريخية.

| الكيان | العدد |
|---|---:|
| الادعاءات | 74 |
| المصادر | 32 |
| الموضوعات | 26 |
| المكونات | 12 |
| العلاقات | 13 |

الادعاءات الأربعة والسبعون كلها pending_review وreview_level=none. لا يوجد اعتماد علمي مؤهل مثبت في هذه العينة. العلاقات الثلاث عشرة كلها بلا claim_id، ولذلك لا يجوز استخدامها كبرهان مستقل على التوافق أو المنع أو الملاءمة. بعض العلاقات تتعلق بمواد دوائية؛ وجودها في البيانات لا يوسع نطاق التطبيق إلى وصف الدواء.

هذه أعداد المعرفة المنظمة المضمنة، وليست إحصاءً لمحتوى مستخدم مثبت سابقًا أو كتالوج عالمي شامل. لا تثبت تغطية كافية لكل التركيبات والتركيزات أو الشعر والبشرة أو المشكلات المركبة.

## التنفيذ

`server/src/intelligence/knowledge-links.ts` يقدم:

- `retrieveKnowledgeGraph(db, {query?, ingredient?, topic_id?, limit?})`: قراءة فقط؛ BM25 الموجود مع اختيار مكون/موضوع وبناء روابط محلية؛ حد افتراضي 6 وأقصى 12 ادعاء، 150 عقدة و200 حافة. query أقصاه300 حرف، ingredient120، topic_id100. الطلب الفارغ لا يفرغ قاعدة المعرفة.
- النتائج: claims مع المصادر الكاملة ومعرفاتها وtrust وحالة المراجعة، وnodes/edges بمعرفات ثابتة، وتحذير صريح. لا يوجد تنفيذ SQL من النموذج أو تعديل قاعدة البيانات داخل البحث.
- الروابط البنيوية وقوائم الوظائف ليست إثباتًا علميًا. supported لا يصبح true لعلاقة إلا بارتباطها بادعاء مسترجع معتمد/منشور راجعه مختص وله مصادر. الحواف غير المسندة تحمل unsourced_relationship_not_evidence.
- `enrichScientificKnowledge(db)`: إدخال اختياري صريح، داخل Savepoint، لا يحدث تلقائيًا بالاسترجاع. INSERT OR IGNORE يحافظ على مراجعات وتعديلات البشر؛ يسجل تاريخ الإدخال ولا يمنح الموافقة.

الطريقة structured_graph_bm25، وليست semantic embeddings أو vector search. يمكن للمنسق تقديم إعادة صياغة بحث مقيدة، لكن هذا الملف لا ينفذ نموذجًا ولا يدّعي فهمًا دلاليًا مستقلاً. BM25 يمسح مجموعة المعرفة الحالية في الذاكرة؛ يحتاج قياسًا/فهرسة إضافية عند توسعها كثيرًا. الروابط غير الموثقة تُعرض كبيانات تدقيق وليست تعليمات توصية.

## إثراء قابل للمراجعة

إضافة اختيارية لأربع خلاصات عربية أصلية قصيرة مرتبطة بثلاثة مصادر أولية، جميعها manual / pending_review / none. لا توجد بيانات اصطناعية في هذا الإثراء. كل خلاصة لها حدود استخدام؛ لم تضف تراكيز أو منتجات أو دراسات مختلقة.

| المعرف | موضوع الخلاصة | المصدر وحدوده |
|---|---|---|
| v32_label_order | ترتيب الملصق واستثناءات النسب الصغيرة والملونات | FDA، سياق أمريكي؛ لا يكشف تركيزًا دقيقًا أو سلامة التركيبة |
| v32_cosing_scope | ذكر INCI لا يعني ترخيص الاستخدام | European Commission، اختصاص الاتحاد الأوروبي فقط |
| v32_cosing_limits | الطبيعة المعلوماتية لـCosIng وضرورة تقييم المنتج | European Commission؛ ليس اعتماد سلامة منتج |
| v32_product_test | تجربة منتج العناية محليًا قبل توسيع الاستخدام | AAD؛ ليست patch test طبية أو ضمانًا لمنع التفاعل |

مصادر فُتحت وتم التحقق من نصوصها في البحث بتاريخ2026-11-25:

1. FDA Cosmetics Labeling Guide: https://www.fda.gov/cosmetics/cosmetics-labeling-regulations/cosmetics-labeling-guide — قسم ingredient labeling، ترتيب المكونات واستثناء ≤1% والملونات.
2. European Commission CosIng: https://single-market-economy.ec.europa.eu/sectors/cosmetics/cosmetic-ingredient-database_en — Important notice حول عدم القيمة القانونية وعدم مساواة INCI بالترخيص.
3. AAD How to test skin care products: https://www.aad.org/public/everyday-care/skin-care-secrets/prevent-skin-problems/test-skin-care-products — خطوات التجربة المنزلية والتمييز عن patch testing الطبي، آخر تحديث معلن2021-08-10.

تخزن روابط ومعلومات المصدر وخلاصات أصلية فقط تحت link_and_summary_only، ولا تُنسخ المقالات أو الصور. يُعاد استخدام معرف المصدر إن كان الرابط موجودًا مسبقًا. يضاف accessed_at بتاريخ تشغيل الإثراء، ولا يمثل مراجعة علمية بشرية أو تأكيدًا بأن محتوى الصفحة أعيد تحميله داخل التطبيق.

في قاعدة baseline النظيفة، أول تشغيل أضاف3مصادر و4ادعاءات وموضوعًا واحدًا: يصبح الإجمالي78ادعاء/35مصدرًا/27موضوعًا، دون تغيير المكونات والعلاقات. تكرار التشغيل يضيف صفر ادعاءات. لا تظهر الادعاءات الجديدة للمرشد قبل المراجعة لأن سياسة USABLE_SQL تستثني pending_review ذات origin=manual. القواعد السابقة تسمح بعرض curated_seed غير المراجعة مع وسمها؛ لم يغير هذا التنفيذ تلك السياسة، ولا يجعلها معتمدة علميًا.

## التحقق والحدود

اختبارات SQLite فعلية تغطي القراءة دون تعديل، حل اسم مكون عربي، المصدر/وسم الثقة، حدود النتائج والمدخل العدائي، منع اعتبار العلاقات غير المسندة مثبتة، استبعاد الادعاءات المغلقة، idempotency، وعدم نشر الإثراء قبل المراجعة. هذه اختبارات بنية وحوكمة وليست قياس retrieval recall أو مراجعة صحة علمية مؤهلة.

الفجوات: العلاقات الموروثة بحاجة لإسناد ومراجعة؛ 12مكونًا لا تكفي تغطية واسعة؛ لا embeddings أو إعادة ترتيب عصبية أو ادعاء بتغطية شاملة. يجب تقييم جودة الاسترجاع على مجموعة مستقلة وربط الاستنتاجات بمصادر معتمدة وإجراء مراجعة علمية ولغوية قبل الإنتاج. الإثراء لا يرفع بوابة الاعتماد الإنتاجي.
