المقارنة مضبوطة ضمن هذه المجموعة الصغيرة: Qwen3.5-2B نفسه، Greedy نفسه، 256 رمزًا لكل محاولة، السؤالان الجديدان نفسيهما. تغيرت فقط طبقة Grammar أو شكل المهمة. الأسئلة وتوقعات الفهم محفوظة قبل التقييم. لا Holdout نهائي ولا Mock.

## ما الذي أثبتته التجربة؟

إزالة Grammar لم تصلح فهم الخطة أو التزام Schema. لذلك ليس لدينا دليل يبرر تعطيل القيود أو تمرير النص الخام إلى الموظف. قدرة النموذج على حديث عام عن نفسه ظهرت في العينة الحرة، لكنها لا تعادل القدرة على بناء استشارة علمية أو استخدام الأدوات والسياق بصورة صحيحة.

النتيجة تخص Prompt الخطة الحالي وGreedy والوزن المحدد، ولا تعزل أثر Sampling عن حجم المهمة ولا تثبت عجز عائلة Qwen في كل إعداد. ليس هناك أساس لتكرار مقارنة2B/4B/Phi أو اعتماد Prompt المختصر الذي فشل سابقًا.

## القيود والقرار

- الحد256 متساوٍ لتحديد الفهم الأولي؛ ليس قياس اكتمال خطط الإنتاج ذات الحد768.
- صحة JSON في المحاولتين المقيدتين لا تساوي صحة الفهم.
- لا تُقبل مخرجات JSON مبتورة أو إجابة حرة تحتوي ادعاءات غير مدعومة.
- القرار: **لا اعتماد لمسار no-Grammar الكامل ولا تخفيف للتحقق العلمي**. يسمح دليل الفشل بتجربة معزولة لمهمة دلالية أصغر دون تعديل المشروع: اختيار النية والأداة فقط ثم التحقق، بدل محاولة استخراج كل الحقول دفعة واحدة. أي تحسن يحتاج قياسًا مستقلًا وتكاملًا فعليًا قبل القبول.

## الأدلة وإعادة الإنتاج

- `results/cases-before-evaluation.json`: السؤالان والتوقعات المحددة مسبقًا.
- `results/raw-responses.jsonl`: الطلبات والمخرجات الخام والمقاييس الستة.
- `results/metadata.json`: بصمات binary/model، سياسة Greedy، حجم الإخراج والمنصة.
- `results/summary.json`: صلاحية البنية والنيات والحقول الأولية دون احتساب نجاح استشارة.
- `run.log` و`results/native.stderr.log`: السجل الكامل بما فيه التحميل.
- `probe_ablation.py`: Harness يستدعي Native الحقيقي. لا يعرض النص الخام كاستشارة معتمدة.
