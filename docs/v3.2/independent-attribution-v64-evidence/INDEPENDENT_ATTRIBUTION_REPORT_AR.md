# إسناد مستقل إلى الحقائق المرصودة — فحص دون استدعاءات نموذج جديدة

استُخدمت مخرجات XML الطبيعية الموجودة فقط. قُسم كل جواب إلى جمل؛ لكل جملة جُربت حقيقة مرصودة أو زوج حقائق مرصودة مع `fidelityCheck` بحد أشد0.70 و`outputViolations`. لم يُغيّر أي نص أو تُحذف جملة رديئة. الإسناد من المدقق المستقل، وليس ادعاء أن النموذج اختار IDs.

**النتيجة قبل الإصلاح:** مر جواب فعلي واحد من4 في الإسناد اللفظي الكامل؛ لكنه جواب المتابعة الذي تجاهل سؤال الذاكرة وأعاد القدرات العامة، فلا يُحتسب نجاحًا حواريًا. جواب أكسدة الأنف غير المسند فشل؛ لم يكن قد استرجع أية معرفة أصلًا.

**ثغرة حرجة مثبتة باختبار سلبي اصطناعي منفصل:** عبارة «أشخص الأمراض وأصف الأدوية وأختلق المكونات أو التركيز أو الدراسات» مرت مستندة إلى حقيقة نافية لهذه الأفعال. نسبة التداخل اللفظي لا تحفظ النفي تلقائيًا، و`outputViolations` لا يغطي هذا الانقلاب. هذه ليست إجابة نموذج أو معرفة علمية؛ إنها حالة أمان للمدقق كُشفت قبل اعتماد المسار.

القرار: لا اعتماد لإسناد مستقل بهذه الأدلة، ولا تخفيف لأي بوابة علمية. يجب إصلاح حفظ النفي في المدقق المستقل واختباره، مع إبقاء حدود التداخل اللفظي وغياب Entailment كامل معلنة. لا يُعد إصلاح المدقق إثباتًا لتحسن فهم النموذج.

الأدلة الأصلية قبل الإصلاح محفوظة في `results.json`, `run.log` و`baseline-validator-metadata.json`. يسجل الملف `evaluate_attribution.mts` مصدر كل جواب والحقائق الفعلية والحالات السلبية الاصطناعية بوضوح.
