# اختبار VLM معزول — Qwen3.5-2B

الحالة الحالية: قيد الاختبار الفعلي على Host، وليس قبول Android أو Samsung.

## ما تحقق

- لا توجد ضرورة مبدئية لتنزيل نموذج لغوي آخر: ملف Qwen3.5-2B Q4_K_M الحالي يحتوي الجزء اللغوي، ومستودع التحويل نفسه عند المراجعة المثبتة `f6d5376be1edb4d416d56da11e5397a961aca8ae` ينشر `mmproj-F16.gguf` المتوافق مع عائلة النموذج.
- نُزل projector مرة واحدة إلى ذاكرة الأدوات، وفُحص الحجم **668,227,264 bytes** وSHA-256 الكامل **7035e9cb8d7c6a9681d07eef9a364783e86ea4cd73faab2eabb4f43a101830c7**. أُعيد استعمال أوزان 2B الحالية بعد فحص SHA الخاص بها؛ لم تتغير قائمة النموذج المعتمد داخل التطبيق.
- فُحصت مصادر `mtmd` في llama.cpp المثبت `b1b770d90d94cad9e9ea5b993bdbc383a522fb28`، واستخدمت كما هي في شجرة بناء Host منفصلة، دون تعديل Runtime أو JNI أو Gradle أو الواجهة الحالية.
- الصور اصطناعية معلّمة بوضوح، ولا تمثل منتجات حقيقية أو معرفة علمية. اختباران لهما السؤال نفسه مع اختلاف الصورة، والأسماء لا تكشف لون العبوة أو شكلها. قراءة الكلمات وحدها لا تكفي لاجتياز التعرف البصري على اللون والشكل.

## حدود الإثبات

الاستدلال البصري الفعلي يختلف عن OCR. نجاح هاتين الصورتين، إن تحقق، يثبت مسار توليد يعتمد على الصورة في Host فقط؛ لا يثبت تعرف المنتجات التجارية، دقة INCI، تطابق الإصدارات، صلاحية المخزون، السلامة العلمية أو الأداء على الهاتف.

عند بدء هذه التجربة لم يكن في Snapshot التطبيق مسار JNI للصورة أو إدارة projector. نُفّذ Wrapper لاحقًا كما يرد أدناه، ودمجه المشترك في Android مسؤولية مرحلة منفصلة تحتاج إلى الاختبار الفعلي. الملفات المتصلة هنا اختبار معزول وليست تفعيلًا شكليًا لزر الكاميرا.

تفاصيل الدمج المطلوبة موثقة في `INTEGRATION_REQUIREMENTS.md`. السجلات الخام وقياسات /proc محفوظة لكل محاولة دون محو حالات الفشل؛ فشل الاعتماد الأول على /usr/bin/time محفوظ كذلك. زمن Host قد يتأثر بأعمال البناء/الاختبارات الأخرى، ولا يستخدم باعتباره قياس Samsung أو مقارنة أداء مضبوطة.

## Wrapper أصلي قابل للدمج

نُفّذ `native/vision.hpp` و`native/vision.cpp` باستخدام libmtmd المثبّت، مع إعادة استخدام `llama_model` و`llama_context` الحاليين. لا يُحمّل نموذج لغوي ثانٍ. التهيئة البصرية Lazy، CPU فقط، وحدّ الصورة 2 MiB و8 ملايين بكسل. تُفحص أبعاد JPEG/PNG من الرأس **قبل** استدعاء Decoder. ثم يُعاد التحقق من الصورة المفكوكة. عدد Image Tokens مستهدف 256 وبوابة صارمة 512، والسياق المدخل 3072 والجواب 256 كحد أقصى.

`LocalVision` ليس Thread-safe؛ يجب أن يستخدم مالك المحرك Executor المتسلسل نفسه للنص والصورة. يجب استدعاء `unload()` للرؤية قبل تحرير النموذج اللغوي أو تبديله. الإلغاء تعاوني باستخدام Atomic المشتركة وCallbacks العقد في mtmd، مع استخدام Abort Callback لسياق llama؛ لا يثبت حدًا زمنيًا قاسيًا لكل Kernel.

المخرجات **مشاهدات بصرية غير مراجعة**، وليست هوية منتج معتمدة أو استشارة علمية. لا يوجد حفظ تلقائي أو اعتماد INCI أو إثبات أصالة أو توفر أو تشخيص. تم تعطيل سجلات mtmd التفصيلية التي قد تطبع السؤال؛ تبقى نتائج التشخيص الخام صريحة داخل مسار المراجعة، وأكواد الخطأ ثابتة.
