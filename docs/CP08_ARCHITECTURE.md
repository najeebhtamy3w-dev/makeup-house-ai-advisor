# CP07 + CP08 — معمارية الذكاء الموحد

الفرع: `cp07-cp08-unified-intelligence` (من `48b8918`). كل شيء خلف `MH_CP07=1`؛ المستشار الافتراضي CP06.2 لم يتغير.

## الطبقات (مُعاد استخدامها لا مُستبدلة)

| الطبقة | الملفات | ما أُضيف في CP08 | أُعيد استخدامه |
|---|---|---|---|
| **A — الفهم العربي** | `server/src/cp07/nlu.ts` | تجريد البادئة «وال»؛ أكثر من نوع منتج في الطلب؛ القيود تُحفظ في السياق (حقل `avoid` الموجود)؛ بدون كحول/سلفات؛ **الإحالة للمكوّن السابق** («طيب لو استخدمته مع…»)؛ **منتج غير محدد** («هذا الكريم») يُسأل عنه ولا يُخمَّن؛ مقارنة مكوّنين؛ «X يفيد؟» دون «هل»؛ «مو دهنية بس فيها لمعة» → مختلطة | `understand()` من CP06.2 دون تعديل |
| **السلامة** | `server/src/cp08/safety.ts` | طبقة مفاهيم مستقلة عن أي نموذج: مجرى الهواء، تورم الوجه/العين/الشفاه/اللسان، حروق/فقاعات/جروح، عدوى، طفح منتشر، حكة شديدة، شامة متغيرة، نزيف؛ إحالات: حمل/رضاعة، أدوية، أطفال، قاصرون، أمراض جلدية، تساقط على شكل بقع، حبوب مؤلمة/ندبات، أعراض مستمرة؛ نفي («ما فيه تورم») | قواعد CP06.2 وCP07 كما هي (تُضاف إليها، لا تُضعف) |
| **B — المعرفة المحلية** | `cp07/store.ts` + الترحيل 008 | لا تغيير في المخطط | كل CP07 (المصادر، الحالات، المراجعة، الإصدارات) |
| **C — البحث العلمي** | `server/src/cp08/research.ts` | تخطيط استعلام من المفاهيم المفهومة فقط؛ قاموس عربي→إنجليزي علمي (مكونات، حالات، 26 موضوعًا غير مغطى)؛ اختيار المصدر؛ إزالة التكرار بين المصادر؛ ترتيب بالصلة؛ مصطلح غير معروف = لا بحث (لا يُرسل نص حر) + فجوة | موصلا CP07 (MedlinePlus، PubMed) بحدودهما وقاطعهما وتخزينهما؛ `storeEvidence` المشترك |
| **D — الاستدلال المؤرض** | `cp07/answer.ts`، `server/src/cp08/fidelity.ts` | الإحالات تُعرض **أولًا**؛ مقارنة مكوّنين جنبًا إلى جنب دون «فائز»؛ بحث كتالوج لكل نوع مطلوب؛ **حارس دقة المعنى** لكل جملة (دعم لفظي، تصعيد يقين، فقدان التحفظ، قلب «استشيري» إلى منع، حذف القيود، أرقام جديدة، صدى السؤال) | محرك CP07 الحتمي (كل جملة = ادعاء) |
| **E — النموذج السحابي الاختياري** | `server/src/cp08/llm.ts` | محوّلا Gemini وOpenAI-compatible؛ مخرجات JSON بجمل واستشهادات؛ حجب الأرقام والبريد؛ الحارس لكل جملة؛ رجوع محلي | واجهة `AIProviderAdapter` + `composeWithAI` + جدول `ai_usage` + سقف الإنفاق من CP06.2 |
| **F — جسر المنتجات** | `cp07/bridge.ts` | «بدون سلفات» إلى قواعد المحل؛ تنبيه أن «بدون كحول» لا يُتحقق منه آليًا | محرك الملاءمة CP06.2 و`science/*` دون تعديل |

## الأوضاع الثلاثة

| الوضع | يتطلب | السلوك عند الفشل |
|---|---|---|
| 1 محلي | لا شيء | — (يعمل دائمًا) |
| 2 بحث علمي | مفتاح المدير `external_search_enabled` + إنترنت | الإجابة نفسها محلية؛ لوحة «أدلة مكتشفة — غير مراجعة» منفصلة؛ لا تدخل المعرفة المعتمدة |
| 3 سحابي | متغيرات بيئة الخادم (مزود + مفتاح + نموذج + أسعار) **و** مفتاح المدير `cloud_llm_enabled` | أي خطأ/مهلة/سقف/رفض دقة ← الإجابة المحلية + سطر حالة؛ لا يُختلق رد سحابي |

الواجهة تعرض شارة لكل إجابة: «إجابة محلية» / «محلية + أدلة مكتشفة غير مراجعة» / «صياغة بمساعدة نموذج سحابي».

## واجهات HTTP
`GET /api/cp08/status` (يرد `{enabled:false}` عند الإيقاف — لا مفتاح أبدًا) · `POST /api/cp08/advisor/chat {message, session_id?, mode}` · `POST /api/cp08/settings` (المدير). ومسارات CP07 لإدارة المعرفة كما هي.

## الشاشات (`web/js/views-intel.js`)
- **المستشار العلمي (تجريبي)** — لكل الموظفين: اختيار الوضع مع سبب تعطيل كل وضع، سياق المحادثة، المصادر بروابط، لوحة البحث غير المراجع، محادثة جديدة.
- **مراجعة المعرفة العلمية** — للمدير: الإعدادات، الفجوات وزر «ابحث»، الادعاءات المعلقة (اعتماد إداري / رفض بسبب / تسجيل مراجعة علمية باسم ومؤهل)، الأدلة المكتشفة، التعارضات.
- تظهر في قائمة «المزيد» فقط إذا أجاب الخادم بأن CP08 مفعّل؛ عامل Android لا يملك هذه المسارات فلا يتغير شيء فيه.
