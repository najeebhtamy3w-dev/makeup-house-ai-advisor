## Phase 3 — التطبيع والمطابقة: Gate 3 ناجحة

`server/src/matching.ts`: دوال نقية، بلا شبكة ولا قاعدة بيانات، وتعمل على الخادم والهاتف.

### ما يدعمه المحرك

| القدرة | التفصيل |
|---|---|
| GTIN | رقم التحقق؛ UPC-12 = GTIN-13 بصفر أول؛ أكواد المحل الداخلية (02 و20–29) لا تُستخدم للمطابقة الخارجية أبدًا |
| تطبيع العربية | التشكيل، الهمزات، التاء المربوطة، أدوات التعريف الملتصقة |
| أسماء العلامات | مرادفات عربية ولاتينية (سيرافي = CeraVe، لاروش بوزيه = La Roche-Posay…) |
| مفردات التجميل | عربي ↔ إنجليزي (غسول = cleanser، مرطب = hydrating…) |
| الأحجام والوحدات | مل، g، fl oz، oz، لتر، بهامش 4% لتقريب الملصقات |
| مؤشرات الإصدار | SPF، اللون/الدرجة، الرائحة، «تركيبة جديدة»، الأطفال/الرجال، شكل المنتج |
| مجموعات الوصف | طبيعة التركيبة (رغوي/مرطب/جل…)، نوع البشرة المستهدف، نهاري/ليلي، الموضع (وجه/جسم/شعر…) |

### القرار

| النتيجة | الشرط |
|---|---|
| `exact_gtin` | الباركود نفسه، ولا تعارض |
| `strong` | العلامة نفسها + كلمات الاسم الأساسية + الحجم نفسه، ولا تعارض |
| `ambiguous` | تشابه مع تعارض، أو نقص معلومة، أو اسم بصياغة مختلفة (مثل نقل عربي لاسم خط المنتج) → إلى إنسان |
| `none` | لا تشابه كافٍ |
| `source_unavailable` | المصدر لم يُجب |

**أي تعارض في العلامة أو الحجم أو اللون أو SPF أو التركيبة أو الإصدار يجعل `strong` و`exact_gtin` مستحيلتين.** الثقة الرقمية للعرض فقط؛ القرار بقواعد صريحة. كل نتيجة تشرح أسبابها وتعارضاتها بالعربية.
