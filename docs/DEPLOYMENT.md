# خطة النشر (لم يُنفَّذ أي نشر)
1. **GitHub:** مستودع مستقل `makeup-house-beauty-advisor`. الكود جاهز (`.gitignore` يستبعد `.env` وقواعد البيانات). لم يُدفع شيء.
2. **الواجهة على Netlify:** مجلد النشر `web/`. يلزم تعيين عنوان API: حاليًا الواجهة تستدعي مسارات نسبية `/api/*`، لذا إما (أ) وكيل عكسي في `netlify.toml` (`/api/* → https://<api-host>/api/:splat`، status 200) أو (ب) أن يخدم الخادم الواجهة بنفسه (الوضع الحالي). الخيار (أ) أنظف.
3. **الخادم + قاعدة البيانات:** عملية Node دائمة مع قرص ثابت: Docker على VPS صغير أو Fly.io/Render/Railway (**قد تكون مدفوعة، لن أنشئ شيئًا دون موافقتك**) أو جهاز المحل نفسه عبر Docker Compose.
4. **HTTPS إلزامي** (الكاميرا لا تعمل بدونه خارج localhost).
5. **أسرار:** `MH_SECRET` و`MH_ADMIN_PASSWORD` متغيرات بيئة فقط.
6. **نسخ احتياطي:** `npm run backup -- <db> <out>` (VACUUM INTO + فحص سلامة؛ مختبر). جدولته يتطلب cron على الخادم.
