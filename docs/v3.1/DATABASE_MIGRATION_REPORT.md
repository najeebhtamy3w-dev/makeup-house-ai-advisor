# قاعدة البيانات

IMPLEMENTED إضافيًا دون migration جديد: حفظ metadata المعتمد في knowledge_settings الموجودة، وتسجيل تغييرات الإعداد ونتائج التحقق في audit_log الموجودة. لا حذف قاعدة ولا إعادة إنشاء بيانات ولا تغيير معرفات أو schema001–009. الأوزان في noBackupFilesDir/local-ai وليست BLOB في SQLite.

تذاكر التحقق مؤقتة في ذاكرة العامل، مرتبطة بالمستخدم، مدة3دقائق، لمرة واحدة، ومحاولة تجديد واحدة فقط؛ لا تُنسخ احتياطيًا. لا تُخزن مخرجات النموذج المرفوضة كأدلة علمية. إعداد desired_active=false المستعاد يمنع تجهيز سياق توليدي. غياب الأوزان بعد الاستعادة يعني استمرار المحرك العلمي بالقواعد؛ لا تنزيل تلقائي.
