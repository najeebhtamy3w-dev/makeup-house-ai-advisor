# قبول Samsung Galaxy S22 Ultra /8GB — كله NOT TESTED

ابدأ بعد توقيع APK بمفتاح المالك نفسه وأخذ MHBAK2 خارج الهاتف. لا تحذف التطبيق السابق. سجّل PASS/FAIL مع نسخة Android وBuild.HARDWARE من إدارة الذكاء المحلي؛ لا نفترض Snapdragon/Exynos.

1. تثبيت code5 فوق الإصدار السابق؛ فتح حساباتك ومنتجاتك وصورك وسجل المراجعة دون فقد.
2. مستشار علمي بلا نموذج؛ مسح باركود حقيقي؛ صلاحية الكاميرا؛ بحث/تعديل/استيراد Excel؛ Android Back وحماية المسودة.
3. مدير فقط: افتح إدارة الذكاء؛ راجع الحجم1.28GB والمساحة؛ تنزيل صريح؛ راقب التقدم؛ إلغاء واستئناف؛ شبكة منقطعة؛ مساحة غير كافية؛ بصمة وتفعيل.
4. زر اختبار النموذج: يجب أن يبلغ bytes>0 ومدة استدلال حقيقي؛ سجّل التشخيص. لا تعتمد بيانات الاختبار جوابًا علميًا.
5. فعّل وضع الطيران: تشغيل التطبيق، منتجات، استشارات مع صياغة محلية أو اقتباس موثق، وغياب أي fallback إلى خدمة سحابية.
6. سؤال يمني وسؤال متابعة ومقارنة وروتين؛ تحقق من أن بيانات المنتج/التوفر لا تتغير أو تُختلق.
7. تورم وضيق تنفس وحرق كيميائي: الإحالة فورية، لا انتظار LLM ولا توصية منتجات. سؤال لاحق يحتفظ بتذكير السلامة.
8. إلغاء توليد؛20 استشارة؛ Back؛ خلفية/مقدمة؛ إعادة تشغيل؛ ضغط RAM؛ لا crash أو تسرب متزايد.
9. إزالة النموذج؛ بقاء المعرفة والمنتجات؛ backup ثم restore بعد إزالة الوزن؛ لا تنزيل تلقائي؛ إعدادات ومعلومات محفوظة.
10. زمن التحميل/أول رمز/رموز بالثانية/RSS والبطارية والحرارة: قارن PERFORMANCE_ACCEPTANCE_THRESHOLDS.md. ارفع تشخيصًا خاليًا من بيانات العملاء.

التوقيع والاختبار العملي فقط يحسمان التثبيت والأداء الحقيقيين. لا تضع PASSED استنادًا إلى Linux أو Chromium.
