# CP06 — دليل تطبيق Android: التثبيت، العمل دون إنترنت، النسخ الاحتياطي والاستعادة

## 1) التثبيت على Samsung (نسخة تجريبية داخلية — لا تُنشر)
1. انسخ `app-debug.apk` إلى الهاتف (USB أو مشاركة داخلية مباشرة؛ لا ترفعه لمتجر أو رابط عام).
2. افتحه من «ملفاتي». عند السؤال اسمح لـ«ملفاتي» بـ«تثبيت التطبيقات غير المعروفة» (الإعدادات ← التطبيقات ← ملفاتي ← تثبيت تطبيقات غير معروفة)، ثم «تثبيت».
3. المتطلبات: Android 7.0 فأحدث (minSdk 24)، و**Android System WebView حديث** (حدّثه من Google Play إن ظهرت شاشة بيضاء أو رسالة «تعذر فتح قاعدة البيانات المحلية»).
4. التحقق من الملف (اختياري): `sha256sum app-debug.apk` يجب أن يطابق القيمة في `CP06_ACCEPTANCE.md`.
5. أو عبر الحاسوب: `adb install -r app-debug.apk` (`-r` يحدّث دون حذف البيانات ما دام مفتاح التوقيع نفسه).

**أول تشغيل:** يظهر «إعداد التطبيق» ← أنشئ حساب المدير. الكتالوج **فارغ تمامًا** (لا منتجات افتراضية ولا بيانات من Staging). من لديه نسخة احتياطية يضغط «لديّ نسخة احتياطية» بدل ذلك.

## 2) ما يعمل دون إنترنت وما يحتاجه
| يعمل دون إنترنت (كل البيانات على الهاتف) | يحتاج الإنترنت (اختياري) |
|---|---|
| تسجيل الدخول والحسابات والصلاحيات | البحث في Open Beauty Facts بالباركود أو الاسم |
| إضافة/تعديل المنتجات، الإدخال السريع، المسودة | جلب صورة المنتج من OBF |
| التصنيف (الفئة/النوع/المنطقة/الوظيفة) والفلاتر والعدّادات | الإكمال التلقائي في الخلفية (طابور الإثراء) |
| البحث بالاسم/العلامة/الباركود، شاشة المسح (إدخال يدوي/قارئ) | |
| الصور من الكاميرا/الاستوديو (تُحفظ في القاعدة المحلية) | |
| استيراد CSV/XLSX | |
| المستشار العلمي، المقارنة، الروتين، المراجعة والتحقق | |
| سجل التدقيق، النسخ الاحتياطي والاستعادة | |

عند انقطاع الإنترنت تعرض شاشة البحث العالمي «المصدر غير متاح» ويستمر كل شيء آخر. **لا يتصل التطبيق بخادم Render إطلاقًا.**

## 3) النسخ الاحتياطي (المدير فقط)
القائمة «المزيد» ← «النسخ الاحتياطي والاستعادة».
1. اكتب **كلمة مرور للنسخة** (8 أحرف على الأقل) وأكّدها ← «إنشاء نسخة احتياطية مشفرة».
2. تظهر نافذة المشاركة في Android: اختر المكان بنفسك — «ملفاتي» (مجلد Download أو ذاكرة USB)، Google Drive، أو حاسوب المحل. الملف بامتداد `.mhbak`.
3. **احفظ كلمة مرور النسخة بعيدًا عن الهاتف** (ورقة في مكان آمن أو مدير كلمات مرور). بدونها لا يمكن لأحد — ولا للمطور — فتح النسخة.

**ما في النسخة:** القاعدة كاملة — المنتجات، الصور، المكونات، المصادر، التصنيف، حالات التحقق والتوفر، الحسابات (كلمات المرور مُجزّأة)، سجل التدقيق.
**الحماية:** AES-256-GCM بمفتاح مشتق PBKDF2-SHA256 (310,000 تكرار) وبصمة SHA-256 للمحتوى. لا تُقرأ أسماء المنتجات ولا تجزئات كلمات المرور داخل الملف (مُختبر). لا يُرسل الملف لأي جهة تلقائيًا.

**التوصية:** نسخة يومية في نهاية الدوام، وأسبوعية خارج الهاتف (حاسوب/USB)، وقبل أي تحديث للتطبيق أو تغيير هاتف.

## 4) الاستعادة
**على هاتف جديد أو بعد إعادة التثبيت:** أول شاشة ← «لديّ نسخة احتياطية». **على هاتف مستخدَم:** المدير ← «النسخ الاحتياطي والاستعادة».
1. اختر ملف `.mhbak` واكتب كلمة مروره ← «التحقق من النسخة».
   يُفك التشفير ويُتحقق من البصمة، ثم تُفتح النسخة **في ملف منفصل** ويُجرى `integrity_check` ويُطابق عدد المنتجات والصور والحسابات مع رأس الملف، ويُرفض أي ملف من إصدار أحدث من التطبيق. **لا يُمس شيء من البيانات الحالية.**
2. إن ظهر «✓ النسخة سليمة» ← «استعادة الآن» ← تأكيد.
   تُحفظ نسخة أمان من البيانات الحالية، ثم تُستبدل القاعدة، ثم يُعاد فتحها وفحصها. **عند أي فشل تُعاد البيانات السابقة كما هي** (كل شيء أو لا شيء — لا استعادة جزئية).
3. سجّل الدخول بحساب من النسخة (كلمات المرور كما كانت وقت إنشاء النسخة).

**رسائل الرفض:** «كلمة المرور غير صحيحة أو الملف تالف/معدَّل» · «فشل التحقق من سلامة النسخة» · «عدد السجلات لا يطابق رأس النسخة» · «النسخة من إصدار أحدث من التطبيق».

## 5) ما يحذف البيانات (تحذير)
إلغاء تثبيت التطبيق · «مسح البيانات» من إعدادات التطبيق · إعادة ضبط المصنع · فقدان الهاتف · تثبيت نسخة موقّعة بمفتاح مختلف (يتطلب إلغاء التثبيت). **في كل هذه الحالات لا يبقى إلا ما في آخر نسخة احتياطية.** التحديث العادي بنفس التوقيع (`adb install -r` أو فتح APK أحدث) يُبقي البيانات — يُتحقق منه على الجهاز.

## 6) للمطور: البناء
```
npm ci
npm run build:mobile         # dist-mobile/: الواجهة + worker.js + sqlite3.wasm
npx cap sync android
cd android && ANDROID_HOME=/path/to/sdk ./gradlew assembleDebug
# الناتج: android/app/build/outputs/apk/debug/app-debug.apk
npm run test:local           # اختبار القبول المحلي (ملفات ثابتة فقط، دون خادم API)
```
المتطلبات: Node 22، JDK 21، Android SDK 36 (build-tools 35/36). لا متغيرات بيئة سرية ولا مفاتيح.
