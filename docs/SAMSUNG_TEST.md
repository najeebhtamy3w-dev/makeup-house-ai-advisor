# اختبار Samsung — CP05 (التعرف والاستيراد والاستكمال + الصور)

الرابط: https://makeup-house-staging.onrender.com — تبدأ بقائمة منتجات فارغة؛ وكل ما تُدخله يُحذف عند سكون الخادم (~15 دقيقة بلا استخدام) أو إعادة نشره. أول فتح بعد السكون يستغرق ~1 دقيقة.

1. افتح الرابط في Chrome أو Samsung Internet وسجّل الدخول بحساب المدير الذي أنشأته في Render (لا ترسل كلمة المرور لأحد).
2. من شريط «نسخة تجريبية» أو «المزيد ← قائمة اختبار Samsung» افتح القائمة: 20 بندًا قصيرًا (الجديد: «المنتجات حسب النوع» و«إدخال منتجات متتالية»؛ وأيضًا الكاميرا، المعرض، الصور، التعرف وجلب المعلومات، البحث بالاسم، استكمال منتج موجود، الاستيراد…).
3. نفّذ كل بند ثم اضغط ✓ نجح / ◐ جزئيًا / ✗ فشل، مع ملاحظة قصيرة عند الحاجة (مثل عدد ثواني الرفع).
4. عند الانتهاء: «إرسال النتائج» ← «مشاركة» أو «نسخ كنص» وأرسل النص. يتضمن معلومات تقنية غير حساسة (نوع المتصفح والشاشة) دون كلمات مرور أو بيانات منتجات.

باركودات عالمية مفيدة للتجربة (منتجات عامة موجودة في Open Beauty Facts، ليست منتجات المحل): `3337875598996` (CeraVe)، `4005900369581` (Nivea body lotion). للبحث بالاسم جرّب: الاسم «Nivea Creme» والعلامة «Nivea» والحجم «150 ml».

ملاحظة: الإجابات محفوظة على الهاتف نفسه، فلا تضيع إذا سكن الخادم. أما المنتجات والصور التجريبية فتُحذف عند السكون — أعد إنشاءها إن احتجت.
