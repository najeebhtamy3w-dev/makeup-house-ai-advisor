# DEVICE ACCEPTANCE CHECKLIST — Samsung Galaxy S22 Ultra (SM-S908E) · Android 16

الحالة: **لم يُختبر على الجهاز بعد.** هذه القائمة للاختبار الميداني الذي يجريه المالك. ضع ✅ أو ❌ واكتب ملاحظة عند الفشل.

## التثبيت
- [ ] انقل `MAKEUP-HOUSE-VISUAL-FINDER-LITE-1.2.0-debug.apk` (يُثبَّت فوق النسخ السابقة دون حذفها) إلى الهاتف وافتحه. سيطلب Android السماح بـ«تثبيت تطبيقات غير معروفة» للتطبيق الذي فتحت منه الملف (مثل «ملفاتي»).
- [ ] إن ظهر تحذير Play Protect: «تفاصيل أخرى ← التثبيت على أي حال» (طبيعي لنسخة Debug).
- [ ] تحقق من SHA-256 للملف (اختياري) بمقارنته مع `SHA256SUMS.txt`.
- [ ] يظهر التطبيق باسم «ميك أب هاوس – الباحث البصري» مع أيقونة عنابية/ذهبية.

## GATE 2 — الكاميرا والمعرض
- [ ] شاشة البداية عاجية مع الأيقونة، ثم الشاشة الرئيسية بالعربية من اليمين لليسار.
- [ ] «تصوير المنتج» يفتح كاميرا Samsung ← التقط ← ✔ ← تظهر الصورة في المعاينة.
- [ ] الصورة العمودية تظهر عمودية (ليست مقلوبة أو مائلة).
- [ ] اضغط «إعادة التصوير» ثم ألغِ من الكاميرا ← تبقى الصورة السابقة وتظهر رسالة «أُلغي التصوير».
- [ ] «اختيار صورة أخرى» يفتح منتقي الصور ← اختر صورة ← تتغير المعاينة.
- [ ] اختر صورة كبيرة جدًا (وضع 200MP إن وجد) ← لا انهيار.
- [ ] لم يُطلب أي إذن (لا كاميرا ولا تخزين).

## GATE 3 — البحث (ضغطة واحدة)
- [ ] اضغط «البحث عن صور مشابهة» ← «جارٍ رفع الصورة إلى Yandex…» ← تُفتح صفحة Yandex مباشرة على **Similar images**.
- [ ] النتائج تخص المنتج المصوَّر.
- [ ] ارجع بزر «الرئيسية»، صوّر منتجًا مختلفًا، ثم ابحث ← النتائج للمنتج الجديد وليست للسابق.
- [ ] كرر مع 3 منتجات على الأقل.
- [ ] فعّل وضع الطيران ثم اضغط البحث ← «لا يوجد اتصال بالإنترنت» مع زر «إعادة المحاولة».
- [ ] (إن ظهر CAPTCHA) أكمله في الصفحة ثم تابع.

## GATE 4 — التنزيل
- [ ] اضغط صورة في النتائج ← في العارض اضغط زر التنزيل ↓ ← تظهر نافذة «حفظ الصورة» ← «تنزيل».
- [ ] تظهر رسالة «تم حفظ الصورة في: الصور › MakeupHouse»، والضغط على الشريط يفتح الصورة.
- [ ] افتح تطبيق «المعرض» ← ألبوم MakeupHouse ← الصورة تُفتح بشكل سليم.
- [ ] نزّل صورتين أو ثلاثًا ← أسماء مختلفة ولا كتابة فوق ملف سابق.
- [ ] اضغط مطولًا على صورة معروضة ← «حفظ الصورة» ← تُحفظ.
- [ ] (إن فشل مصدر ما) تظهر رسالة فشل عربية واضحة، وليس نجاحًا وهميًا.

## GATE 5 — الاستقرار
- [ ] نفّذ 20 دورة: تصوير ← بحث ← تنزيل ← رجوع، دون انهيار أو تجمّد.
- [ ] دوّر الشاشة في الشاشة الرئيسية وفي صفحة البحث ← لا تضيع الصورة ولا تُعاد الصفحة.
- [ ] أغلق التطبيق من قائمة التطبيقات الأخيرة ثم افتحه ← يعمل طبيعيًا.
- [ ] الإعدادات ← التطبيقات ← التطبيق ← التخزين: حجم الذاكرة المؤقتة صغير (بضع مئات KB).

## أزرار صفحة البحث
- [ ] «رجوع» يرجع داخل الصفحة، ومن أول صفحة يعود للرئيسية.
- [ ] «إعادة تحميل» تعمل.
- [ ] «فتح في المتصفح» يفتح الصفحة نفسها في Chrome أو Samsung Internet.
- [ ] «الرئيسية» يعود للشاشة الرئيسية مع بقاء الصورة.
